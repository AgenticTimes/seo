# 关键词分析：现有逻辑与可产出的结论（调研）

> 目的：把「现在能得出什么结论」和「行业上还能怎么分析」分开讲清楚。
> 结论先行：当前系统只能回答 **需求在不在动、动得是否持续**；不能回答 **值不值得做**。

---

## 1. 当前系统实际在算什么

### 1.1 输入

| 输入 | 来源 | 粒度 |
|---|---|---|
| 时间序列 | Google Trends（或 Fake） | 每窗口 1 条，降采样到 ≤24 点 |
| 窗口 | 7D / 30D / 90D / 12M / 5Y | 每个窗口独立归一化 0–100 |
| 相关词 | Related Queries 合并去重 | 每条带 Top/Rising/Breakout 来源 |
| 图谱位置 | 父节点 + depth | depth ≤ 2 |

### 1.2 规则（BR-01 的实际实现）

```
无 30D 数据                          → 数据不足
30D 下降                             → 下降
30D 平稳                             → 平稳
30D 上涨，缺 90D 或 12M              → 数据不足
30D↑ 且 90D↑ 且 5Y↑                  → 长期赛道
30D↑ 且 90D↑ 且 12M↑                 → 持续增长
30D↑ 且 90D↑ 且 12M 非涨             → 新兴
30D↑ 但 90D 未涨，12M↑               → 平稳
30D↑ 但 90D 未涨，12M 非涨           → 短期波动
```

实现细节（影响结论质量）：

- `Direction` 只比较序列**首尾两点**，不看斜率、加速度、波动
- 7D 数据被采集和存储，但**没有参与任何判定**
- 每个窗口只取一次样本，没有重复采样，采样噪声未处理
- 阈值只有一个 `MinChangePct = 10%`

### 1.3 输出

| 输出 | 取值 |
|---|---|
| Verdict | 未判定 / 数据不足 / 下降 / 平稳 / 短期波动 / 新兴 / 持续增长 / 长期赛道 |
| State | 待验证 / 已验证 / 种子候选 / 过于宽泛 / 已放弃 |
| Source | 种子 / 热门 / 上升 / 暴涨 |

## 2. 当前能得出的结论（全集）

| 结论 | 触发条件 | 建议动作 | 可信度 |
|---|---|---|---|
| 值得进入下一轮 | 新兴 / 持续增长 | 扩子词或评估机会 | 中 |
| 长期赛道，不是新机会 | 5Y 涨且 90D 涨 | 作为成熟市场参考，不追新 | 中 |
| 短期噪声 | 短期波动 | 不收 | 中 |
| 需求在萎缩 | 下降 | 放弃 | 中高 |
| 没有增长 | 平稳 | 观察 | 中 |
| 证据不足 | 数据不足 | 补窗口或换 Topic | — |
| 词太泛 | 人工标记过宽 | 关闭并换更具体的种子 | 人工 |
| 声量突增但量级未知 | 暴涨 | 只作线索，不作排序依据 | 低 |

**一句话**：这些结论描述的是「趋势形状」，不是「商业机会」。

## 3. 当前明确不能得出的结论

| 问题 | 为什么不能 |
|---|---|
| 绝对搜索量 | Trends 只给 0–100 相对指数 |
| 付费意愿 | 指数与购买无关，需外部证据 |
| 市场规模 | 无绝对量、无客单价 |
| 竞争强度 | 没有 SERP / 品牌占比 / 广告密度 |
| 搜索意图 | 没有意图分类，只有字符串 |
| 是否为同一需求 | 聚类（BR-05）未实现 |
| 区域差异 | 一次查询只对一个 geo |
| 季节性 | 未做分解，5Y 曲线只取首尾 |

## 4. 行业成熟方法（调研）

### 4.1 趋势分解：STL

Google 自己的研究（On the Predictability of Search Trends, 2009）用 STL 把序列拆成
**趋势 + 季节 + 残差**，然后外推趋势、复用上一周期季节项做预测。

对当前系统的启示：

- 现在把「季节性上涨」误判成「新兴」的风险很高
- 应该用 5Y 数据先分离季节项，再判断趋势项
- Google 的研究结论：约一半热门查询 12 个月可预测，平均绝对误差约 12%；
  健康/餐饮/旅游类可预测性高，娱乐/社交网络低

### 4.2 季节形态分类

业界常用四类，直接对应不同动作：

| 形态 | 特征 | 动作 |
|---|---|---|
| 单峰 | 每年一次尖峰 | 一个发布时间点 |
| 双峰 | 春秋两次 | 两个更新周期 |
| 锯齿/周内 | 周内周期 | 工作日发布 |
| 缓升平台 | 慢慢爬升后长期高位 | 爬升前发布 |

结论：**只看 12 个月无法区分「增长」和「季节高位」**，必须用 5Y。

### 4.3 时间窗分工

| 窗口 | 能回答 |
|---|---|
| 7D | 新闻/突发事件 |
| 30D | 当前动量 |
| 90D | 近期趋势是否持续 |
| 12M | 年度周期 |
| 5Y | 结构性变化、季节形态 |

当前系统采集了 7D 却不用，30D 只做首尾比较，等于浪费了行情信息。

### 4.4 归一化与采样噪声

- 同一词、同一月，换个时间范围，指数会变（每窗口重新归一化）
- 匿名会话返回的是采样值，同一查询多次结果可能不同
- 缓解手段：重复采样取中位数、用 Topic 代替 Search term、固定 geo/time/category

这直接决定「下降 18%」是真下降还是噪声。

### 4.5 机会评分框架（需要外部数据）

调研到的三类主流做法：

1. **DICER**：Demand / Intent / Competition / Existing traction / Revenue relevance，各 0–3 分
2. **100 分缺口模型**：业务价值 25 + 意图匹配 20 + 可排名性 20 + 缺口深度 10 + 点击潜力 10 + 现有资产 10 + 时效 5，再扣罚分
3. **简化公式**：Opportunity = sqrt(volume) × (100 − difficulty)，上升词 +10 / 下降词 −5

共同点：**都必须引入 Trends 之外的数据**（关键词量、难度、SERP、CPC、GSC）。
所以它们不能直接塞进当前 `TrendsGateway`，需要在 `evaluation` 上下文里做。

### 4.6 意图分类

通用四分类：信息型 / 商业调研型 / 交易型 / 导航型。
判断依据：修饰词（how/best/vs/buy/login/download）、SERP 形态（AI Overview、购物、地图）、品牌词。

当前系统没有这一步，所以 `claude ai login`（导航型）和 `ai agent memory`（信息型）被同等对待。

### 4.7 竞争评估

- 品牌词占比：`ai` 的子词里 Gemini/Grok/Kimi/Claude 占比高，说明是红海入口
- SERP 饱和度：前 10 是否被大站占满
- 零点击率：AI Overview / 精选摘要会吃掉点击
- 广告密度：高 CPC + 高广告位 = 商业价值高但进入难

## 5. 建议扩展后的结论体系

### 5.1 四类结论

| 类别 | 结论 | 需要的证据 |
|---|---|---|
| 机会 | 新兴机会 / 持续增长 / 长期赛道 / 季节性机会 / 蓝海细分 | 趋势分解 + 竞争 + 意图 |
| 观察 | 数据不足 / 噪声 / 季节性 / 短期波动 | 重复采样 + STL |
| 放弃 | 下降 / 过宽 / 品牌红海 / 伪需求 | 趋势 + 品牌占比 + 外部验证 |
| 待验证 | 需付费验证 / 需竞品验证 / 需区域验证 | 外部证据 |

### 5.2 关键指标与初始阈值

| 指标 | 算法 | 初始阈值 | 用途 |
|---|---|---|---|
| 动量 | 近 30D 对数斜率 | > 0 | 当前是否在涨 |
| 加速度 | 30D 斜率 − 90D 斜率 | > 0 | 是否在加速 |
| 季节强度 | 季节项方差 / 总方差 | > 0.3 | 是否应做季节判断 |
| 结构增长 | STL 趋势项 5Y 斜率 | > 0 | 剔季节后的真实增长 |
| 尖峰比 | max / median | > 3 | 是否事件驱动 |
| 品牌占比 | 子词命中品牌表比例 | > 0.4 | 是否红海入口 |
| 簇内聚度 | 同簇语义相似度均值 | < 0.5 警告 | 是否同一需求 |
| 语言偏移 | 非目标语言占比 | > 0.3 警告 | geo 是否选错 |

### 5.3 可信度分级

| 级别 | 能回答 | 例子 |
|---|---|---|
| A | 趋势结构 | 在涨/在跌/季节/长期 |
| B | 需求存在 | 有人在搜、在增长 |
| C | 商业价值 | 值不值得做、能不能赚钱 |

当前系统只到 A，部分到 B；C 必须接外部数据。

## 7. 结论的诚实边界

- Trends 的指数**不是搜索量**，任何「量级」结论都不成立
- 采样噪声会让短期变化看起来像趋势，单次查询不足以定论
- 品牌词热度反映的是竞争，不是需求空白
- 「新兴 + 持续增长」只说明**注意力在增长**，不说明**有人愿意付钱**
- 最终判断必须回到：谁在搜、搜完想干什么、现有产品是否解决了
